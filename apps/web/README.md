# Duo LAN Web

Frontend Angular de Duo LAN.

- Angular 21 + TypeScript estricto.
- Tailwind CSS 4 con tokens de Duo LAN.
- Rutas lazy por feature.
- `HttpClient` con proxy `/api` hacia la API local.
- Environments en `src/environments/`.

## Comandos

```bash
npm run start -w @duolan/web
npm run build -w @duolan/web
npm run test -w @duolan/web
npm run lint -w @duolan/web
```

La documentación de producto, arquitectura y diseño vive en la raíz del monorepo, dentro de `docs/`.
